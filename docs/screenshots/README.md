# UI screenshots

These screenshots document the current intended visual language of the checked-in prototype.

- `home.svg` — landing page / product positioning
- `create-challenge.svg` — first-to format and game-pool selection
- `victory-card.svg` — NFL-style side-by-side game result comparison

The checked-in UI currently uses abbreviation badges instead of third-party game logos. Artwork is intentionally treated as catalog metadata rather than hard-coded into match logic.
